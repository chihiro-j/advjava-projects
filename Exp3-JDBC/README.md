# 📘 JDBC Project (Java Database Connectivity)

## 📌 Aim
To design a Java program that connects to a MySQL database using JDBC and performs basic operations.

---

## 🎯 Objectives
- Understand JDBC architecture.
- Learn how to connect Java with MySQL.
- Practice SQL queries via JDBC.
- Use PreparedStatement and ResultSet.
