📘 Student Registration Form
📌 Overview
This project contains a Java-based Student Registration Form.
It demonstrates how to build a simple form interface, validate user input, and manage student data.
The focus is on Java fundamentals, GUI design, and event handling.

🛠️ Features
📝 Input fields for student details (Name, Age, Gender, Course, etc.)

✅ Validation checks for required fields and numeric input

🎛️ GUI built using Java Swing

🔄 Submit and Reset functionality

💾 Display or store registered student details
