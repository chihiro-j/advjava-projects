# Advanced Java Projects

This repository contains Advanced Java laboratory experiments and a web application project developed as part of academic coursework. It includes Java Swing, JDBC, TCP socket programming, RMI, Servlets, and the ShopSphere project.

## 📂 Repository Structure

| No. | Experiment / Project | Description |
|---|---|---|
| 1 | `Exp1-StudentRegistration` | Student Registration Form |
| 2 | `Exp2-Calculator-using-Java-Swing` | Calculator using Java Swing |
| 3 | `Exp3-JDBC` | Database connectivity and JDBC operations |
| 4 | `Exp4-client server` | TCP client-server communication |
| 5 | `Exp5-RMI` | Remote Method Invocation |
| 6 | `Exp6-Servlet` | Java Servlet-based web application |
| 7 | `ShopSphereProject` | E-commerce web application project |

## 🛠️ Technologies Used

- **Java** — Core programming and application logic
- **Java Swing** — Graphical user interfaces
- **JDBC** — Java database connectivity
- **TCP Sockets** — Client-server communication
- **Java RMI** — Remote method invocation
- **Servlets** — Server-side web application development
- **HTML, CSS, and JavaScript** — Web interface technologies, where applicable
- **Database technologies** — Data storage and retrieval, where applicable

## 🚀 How to Use This Repository

1. Open the required experiment folder.
2. Read its source code and any included `README.md` or instructions.
3. Check the required Java version, libraries, database configuration, and other dependencies.
4. Follow the experiment-specific instructions to compile and execute the program.

**Note:** Some experiments may require additional setup, such as a database server, a servlet container (Tomcat), or an RMI registry. The exact requirements depend on the experiment.

## 🎯 Objectives

- Understand Advanced Java programming concepts.
- Practice graphical user interface development using Swing.
- Learn database operations through JDBC.
- Implement network communication using TCP sockets.
- Understand distributed applications using RMI.
- Develop server-side web applications using Servlets.
- Apply programming concepts in a web application project.

This repository is maintained for learning, practical implementation, and academic reference. Each experiment demonstrates a specific concept of Advanced Java and related application development.
